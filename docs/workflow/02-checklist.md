# Checklist Pre-Impressao

## Checklist Rapida

### No Blender (Modelagem)
- [ ] Mesh manifold (watertight) - sem buracos
- [ ] Normais recalculadas (apontando para fora)
- [ ] Sem geometria cruzada (non-manifold edges)
- [ ] Escala aplicada (Ctrl+A > All Transforms)
- [ ] Dimensoes corretas verificadas (N-panel)
- [ ] Espessura de parede >= 0.4 mm (bico 0.4mm)
- [ ] Furos desenhados 0.2 mm maiores que necessario
- [ ] Folgas de encaixe incluidas (0.2-0.3 mm para moveis)

### Na Exportacao
- [ ] Formato correto (STL binary / STEP / 3MF)
- [ ] Escala de exportacao correta
- [ ] Apenas objetos necessarios exportados (Selection Only)
- [ ] Modifiers aplicados

### No Bambu Studio (Slicer)
- [ ] Impressora correta selecionada (A1 + tamanho do bico)
- [ ] Filamento correto selecionado (tipo + marca)
- [ ] Perfil de processo adequado (qualidade vs. velocidade)
- [ ] Modelo na orientacao otima
- [ ] Modelo toca a cama corretamente
- [ ] Suportes habilitados (se necessario)
- [ ] Brim habilitado (se modelo pequeno ou alto)
- [ ] Infill adequado ao uso (funcional vs. decorativo)
- [ ] Preview de camadas verificado
- [ ] Tempo estimado aceitavel
- [ ] Uso de material estimado aceitavel

### Na Impressora
- [ ] Placa de construcao limpa (lavada com agua e detergente)
- [ ] Tipo correto de placa instalada e selecionada
- [ ] Filamento correto carregado (tipo e cor)
- [ ] Filamento suficiente para a impressao
- [ ] Bico limpo e sem obstrucao
- [ ] Bico correto instalado (padrao vs. endurecido)
- [ ] Cola aplicada (se necessario - ABS, ASA, PC, PA)

### Pos-Impressao
- [ ] Esperar cama esfriar (< 35C)
- [ ] Remover modelo cuidadosamente
- [ ] Remover suportes
- [ ] Verificar dimensoes (se critico)
- [ ] Pos-processamento (lixar, pintar, colar)
